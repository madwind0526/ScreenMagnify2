# Rules

> 이 프로젝트의 규칙과 컨벤션. 모든 sub-agent가 반드시 따라야 함.

## G-01: 코드 주석은 영어만 사용 (MANDATORY)

**규칙:** 모든 코드 주석(`//`, `/* */`, `///`)은 영어. UI 텍스트는 한국어.

## R-01: ScreenMagnify와 같다고 한 동작은 원본 코드를 비교해서 맞춘다

**규칙:** "ScreenMagnify처럼/그대로"인 동작(배율 단계 `nextZoom`/`clampZoom`(0.5~64), 휠 24 ms 제한, 장치 분기(CPU=JS 리샘플러, GPU=WebGL), GPU 전용 방법과 대체(NIS->Lanczos3, x4plus->x4v3), 모델 순서, 배율 HUD 스타일)은 원본 함수를 그대로 옮기고, 끝나면 남은 차이를 직접 나열한다.
**이유:** 곱셈식 배율, 항상 WebGL 사용 등으로 달라졌다가 사용자가 직접 지적했다("그대로 복사하라고 했는데").
**적용 시점:** 원본에 있는 기능을 ScreenMagnify2에 넣을 때마다.

## R-02: AI 입력을 줄이지 않는다

**규칙:** AI에는 돋보기 영역을 원본 해상도로 넣고, 256px보다 크면 워커가 타일로 처리한다(192 core + 32 pad). `aiMaxSize`(기본 -1 = 돋보기 영역, 0 = 모델·장치별 표, 또는 px)는 AI를 건너뛰고 필터를 보여 줄 한계만 정한다. x4plus와 NIS는 GPU 전용.
**이유:** 입력을 256px로 줄여 넣으면 글씨가 원본보다 깨진다(1.0배에서 확인). 회사에서는 같은 모델이 깨끗했다.
**적용 시점:** 워커/한도/모델 목록을 수정할 때.

## R-03: UI 취향

**규칙:** 모서리는 직각(border-radius 0), 창은 컴팩트하게, 설정 창 폭은 메인 창 폭과 같게, 설정 창 높이는 마지막 줄 아래 여백 약 24 px를 측정해서 정한다. 한 줄이어야 하는 선택 라벨("돋보기" 등)은 짧게 하고 `.select`는 `white-space: nowrap`. 모델 목록은 모델 크기 순.
**적용 시점:** 설정/메인 창을 고칠 때.

## R-04: 디자인은 샘플을 이미지로 보여 주고 고르게 한다

**규칙:** 모양/질감처럼 취향이 걸리는 것은 여러 후보를 한 장의 이미지(`samples/`)로 보여 주고 사용자가 고르게 한다. 이미지는 로컬 ComfyUI(Flux schnell)로 질감만 만들고, 모양과 크기는 CSS로 그린다.
**이유:** 사용자가 "여러 개를 sample로 이미지로 보여줘"라고 요청했다. 이미지 모델이 만든 전체 그림은 원형/사각 크기에 맞지 않는다.

## R-05: 테스트용 코드는 반드시 지운다

**규칙:** `main.js` 끝에 임시로 붙이는 `SM_TEST` 훅은 작업이 끝나면 지운다(`grep -c SM_TEST electron/main.js`가 0). 큰 수정 뒤에는 기본 조작(휠, Ctrl+휠, CPU/GPU, Freeze/실시간)을 다시 돌려 본다.
**이유:** 실시간 모드를 추가하다 `showBadge`를 통째로 지워 휠이 죽은 적이 있다.
